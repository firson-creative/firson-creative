# Setup

1. Create/open your GitHub profile repository:
   `firson-creative/firson-creative`
2. Copy `README.md` and the entire `assets/` folder into the repository root.
3. Commit and push.
4. The custom SVG panels will render directly inside the GitHub Profile README.

## Optional
Replace the `F` avatar in `assets/hero.svg` with your own profile photo by editing the SVG.
